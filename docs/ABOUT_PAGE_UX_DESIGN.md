# 📐 About Us Page - UX Design Document

## 🎯 Mục Tiêu UX

Trang About Us được thiết kế để:
1. **Xây dựng niềm tin** - Chứng minh năng lực và uy tín
2. **Kể câu chuyện** - Tạo kết nối cảm xúc với người dùng
3. **Thể hiện giá trị** - Làm rõ điểm khác biệt cạnh tranh
4. **Khuyến khích hành động** - Dẫn dắt người dùng đến conversion

## 🎨 Design System

### Color Strategy
- **Primary Gradients**: Blue → Purple (modern, tech-focused)
- **Accent Colors**: Yellow (awards), Red/Green/Blue (values)
- **Backgrounds**: Subtle gradients with decorative orbs
- **Dark Mode**: Full support với appropriate adjustments

### Typography Hierarchy
1. **Hero H1**: 4xl → 7xl (massive impact)
2. **Section H2**: 4xl → 5xl (clear hierarchy)
3. **Card H3**: xl → 2xl (scannable)
4. **Body Text**: base → lg (readable)

### Spacing System
- **Section Padding**: py-20 → py-32 (generous breathing room)
- **Container Max Width**: 6xl (1280px) for optimal readability
- **Grid Gaps**: 6-8 (consistent rhythm)

### Animation Strategy
- **Scroll Animations**: whileInView với viewport: once
- **Hover States**: Scale, translate, color shifts
- **Timing**: 300-700ms (smooth but not slow)
- **Easing**: ease-out (natural feel)

---

## 📱 Responsive Design

### Breakpoints
- **Mobile**: < 768px (1-column layouts)
- **Tablet**: 768px → 1024px (2-column)
- **Desktop**: > 1024px (3-4 column)

### Mobile Optimizations
- Stack all sections vertically
- Larger touch targets (min 44px)
- Remove complex hover states
- Prioritize essential content
- Optimize image sizes

## 🎓 UX Best Practices Applied

### 1. **F-Pattern Reading**
- Important content on left
- Headers and icons draw eye
- Key information in first 2 sections

### 2. **Progressive Disclosure**
- Start broad (mission/vision)
- Get specific (why choose, team)
- End with proof (testimonials, partners)

### 3. **Visual Hierarchy**
- Size indicates importance
- Color draws attention
- Spacing creates rhythm
- Animation guides focus

### 4. **Social Proof Pyramid**
- Stats (numbers)
- Testimonials (individuals)
- Logos (companies)
- Awards (organizations)

### 5. **Storytelling Arc**
- Hook (Hero)
- Context (Mission/Vision)
- Journey (Timeline)
- Characters (Team)
- Proof (Testimonials)
- Resolution (CTA)
